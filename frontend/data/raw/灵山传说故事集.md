灵山传说故事集

# 前言

灵山胜境所在的太湖之滨，自唐代以来就流传着众多与佛教相关的传说故事。这些故事或出自史书记载，或流传于民间口耳，共同构成了灵山丰富的文化底蕴。本文集整理收录七则流传最广的灵山传说，以供景区讲解和游客了解之用。


# 故事一：玄奘命名“小灵山”

唐贞观十九年（公元645年），玄奘法师历经十七载、行程五万里，终于从天竺取回真经657部，回到长安。在翻译佛经的岁月里，他听说江南太湖之滨有一处山水绝佳之地，便前往游览。当玄奘来到马山秦履峰南麓，只见层峦叠翠、湖水环绕、云雾缭绕，不禁感叹道：“此处的景色，与天竺灵鹫山毫无差别啊！”（“无殊西竺国灵鹫之胜也”）。

灵鹫山（梵语Gṛdhrakūṭa，音译“耆阇崛山”）是印度佛教最重要的圣地之一。释迦牟尼佛成道后，曾在此山宣讲《法华经》《无量寿经》《般若经》等大乘经典。玄奘将马山命名为“小灵山”，正是希望佛法能在此地生根发芽，如同天竺灵鹫山一般成为江南的佛教圣地。


# 故事二：杭恽将军舍山建寺

唐代有一位名叫杭恽的将军，解甲归田后隐居在马山。他听闻玄奘法师盛赞此地“类若天竺灵鹫”，深受触动，决定将自己的数十亩山林捐出，用以建造佛寺。杭恽亲自督工，带领乡民开山辟石、筑基立栋。寺院建成后，玄奘法师派遣大弟子窥基法师前来担任住持。

窥基法师是玄奘最杰出的弟子之一，被尊为“慈恩大师”，是法相唯识宗（慈恩宗）的重要奠基人。他不仅精通佛理，还善于著述，有“百本疏主”之称。在窥基的主持下，小灵山寺很快成为江南闻名的佛教道场，四方信众络绎不绝。杭恽将军也因此被视为灵山的第一位大护法。


# 故事三：赵朴初与灵山大佛

1994年4月，87岁高龄的赵朴初（全国政协副主席、中国佛教协会会长）来到马山小灵山考察。站在秦履峰上，望着脚下这片千年佛教遗址，赵朴老心潮澎湃。他查阅随身携带的史料，确认此地确为唐代小灵山寺遗址。随后，他即兴填词《忆江南》一首：

“灵山胜境，万古云霄。太湖三万六千顷，八十八米大佛高。福慧双修好！”——赵朴初《忆江南·灵山》

赵朴老不仅为未来的大佛取名“灵山大佛”，更为其赋予了宏大的文化使命——完成神州大地“五方五佛”的完美格局。他说：“东方应有东方的大佛，灵山大佛建成之日，便是五方五佛圆满之时。”1997年11月15日，灵山大佛开光大典举行。赵朴老于2000年示寂，灵山大佛成为他留给后人的最后一份佛教文化遗产。


# 故事四：九龙灌浴——太子的七个脚印

据《本行经》记载，释迦牟尼（名悉达多）降生于古印度迦毗罗卫国的蓝毗尼花园。传说摩耶夫人怀胎十月，按当地习俗回娘家待产，途经蓝毗尼花园时被美景吸引，下车漫步。她右手攀住一棵无忧树枝，太子便从右胁降生。太子一出生便向东、南、西、北四个方向各走七步，每走一步脚下生出一朵莲花，天上九龙飞来，口吐香净之水，为太子沐浴净身。这便是佛教中“步步生莲”和“九龙灌浴”典故的由来。灵山的九龙灌浴雕塑，用180余吨青铜将这神圣一幕凝固为永恒，每天在音乐和喷泉中华丽再现。


# 故事五：佛手与福寿

灵山有一句口诀：“摸佛手，添福寿”。这句话在无锡民间口耳相传。相传灵山大佛开光后不久，有一位年过七旬的老太太来灵山朝拜。她走到天下第一掌前，用颤巍巍的手摸了佛手。回家后，老人多年的关节炎奇迹般地好转了。消息传开后，“摸佛手添福寿”的说法越传越广。虽然这只是一个民间传说，但它反映了人们对于健康长寿的美好期盼。如今，每天都有数千游客到此摸佛手祈福，“佛手”与“福寿”的谐音成为灵山最温暖的祝福。


# 故事六：祥符三桥——慈恩、普渡、大觉

祥符禅寺门前有三座石桥，分别是慈恩桥、普渡桥、大觉桥，合称“祥符三桥”。三座桥各有寓意：慈恩桥代表“慈”，提醒人们要以慈悲心待人；普渡桥代表“悲”，寓意普渡众生脱离苦海；大觉桥代表“智”，象征以智慧觉悟真理。据说跨过这三座桥，便完成了一次“慈、悲、智”的心灵洗礼。北宋大中祥符年间，宋真宗下诏重修小灵山寺并改名“祥符禅院”，这三座石桥便是当时的遗构，虽经历代修缮，但桥基仍是北宋原物。


# 故事七：梵宫的白象——缅甸的友谊使者

灵山梵宫门前矗立着两尊汉白玉白象雕塑，它们来自缅甸。在佛教文化中，白象是神圣的象征——摩耶夫人梦见一头六牙白象从右胁入胎，随后便怀上了悉达多太子。因此白象被视为佛陀的化身。这两尊白象是缅甸佛教界赠送给灵山的珍贵礼物，象征着中缅两国佛教文化交流。白象背上驮着宝瓶，谐音“太平”，寓意天下太平、国泰民安。
