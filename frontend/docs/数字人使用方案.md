# 讯飞虚拟人使用方案

## 配额

- 600 分钟 WebSocket 连接时长（免费测试）
- 计费方式：连接时长，非说话时长

## 策略

**按需连接，用完即断**。

- 默认状态：显示静态 PNG 形象（零消耗）
- 用户点击"开始对话" → 建立 WebSocket → 展示 3D 数字人
- 对话结束 / 用户离开 → 断开 WebSocket

## SDK 部署

1. 下载 SDK 包 → 放到 `public/sdk/` 目录
2. 确保 `index.js` 路径正确（`/sdk/index.js`）
3. 播放器分包（`xrtc-player-*.js`）与入口同目录
